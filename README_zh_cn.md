这是一个机械动力附属模组，使你无需建造守卫者农场即可自动化生产海晶石，实现加速铜块的氧化（使其更快锈蚀变色），将失活的珊瑚 / 失活的珊瑚块复原为相应的未失活变种，使三叉戟可合成。

由[DaviO](https://github.com/davioliva16)制作。[冰焰(tozyx)](https://github.com/tozyx)复刻。
***
需要机械动力 5.1.e 或者更新的版本  
推荐但不强制要求使用JEI/EMI物品查看器查看配方。
